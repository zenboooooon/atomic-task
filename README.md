# atomic-task

**「見る」「近づく」「跳ぶ」を練習したAIは、複雑な課題も学びやすくなるか。**

ゲーム画面を見て動くAIに、基本的な行動を個別に学ばせ、その経験が複数の行動を組み合わせる課題に役立つかを調べています。

## 何を学習するのか

Unityで作った3D環境で、まず次の3つの課題を練習します。これらの小さな課題を「原子タスク」と呼んでいます。

| 原子タスク | やること |
|---|---|
| look | 目標を画面の中央に捉え続ける |
| approach | 目標に近づいて触れる |
| jump | ジャンプして台の上に乗る |

その後、**障害物を避け、台へ跳び乗り、台の上の宝に触れる**複合タスクを学習します。現在の版はv0.10で、目標・台が橙、自機がシアンの環境を使っています。

## 基本練習の経験をどう使うのか

AIの中には、画面と過去の行動を読み取る共有部分と、各課題の操作を決める部分があります。原子タスクで学んだ共有部分を複合タスクへ引き継ぎ、複合用の操作を新しく学ばせます。

次の3通りを比べて、基本練習の経験が学習にどう影響するかを確かめます。

| 条件 | 複合タスクの学び方 |
|---|---|
| P | 練習済みの共有部分を固定して、操作を学ぶ |
| S | 共有部分も操作も、最初から学ぶ |
| F | 練習済みの共有部分も更新しながら、操作を学ぶ |
